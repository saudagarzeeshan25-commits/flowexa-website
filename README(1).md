# Flowexa Website — GitHub Upload

This is the simplified GitHub Pages version. All website files are in the repository root so they can be uploaded together without creating folders.

Upload every file in this folder directly to the GitHub repository root.

Required:
- index.html
- styles.css
- app.js
- favicon.png
- flowexa-logo-exact.png
- flowexa-f-mark-exact.png
- four PDF resources
- .nojekyll

Do not upload the ZIP itself as the website.
